# SolarCool — نظام مقارنة تبريد الألواح الشمسية

مشروع التخرج: نظام متابعة وتحكم لحظي بيقارن بين 3 ألواح شمسية —
**مبرد بالمياه**، **مبرد بالهواء**، و**بدون تبريد**.

## مكونات النظام

1. **الداشبورد** (`index.html`): صفحة ويب واحدة فيها كل حاجة —
   كروت حرارة الثلاث ألواح، رسوم بيانية لايف للحرارة والقدرة، مؤشر البطارية،
   وسلايدرز للتحكم في المروحة والطلمبة، مع زرار عربي/English.
   شغالة ببيانات تجريبية لحد ما توصل Firebase.
2. **الباك إند**: Firebase Realtime Database — القواعد في
   `firebase/database.rules.json`.
3. **الفيرموير**: `firmware/solar_cooling_esp32/solar_cooling_esp32.ino`
   كود الـ ESP32 كامل: يقرأ الحساسات، يبعت لـ Firebase، ويظبط سرعة
   المروحة والطلمبة من الداشبورد.

## شكل قاعدة البيانات

| المسار | مين بيكتب فيه | المحتوى |
|---|---|---|
| `/panels/water` | ESP32 | حرارة، جهد، تيار، قدرة اللوح المبرد بالمياه |
| `/panels/air` | ESP32 | نفس الحاجات للوح المبرد بالهواء |
| `/panels/none` | ESP32 | نفس الحاجات للوح بدون تبريد |
| `/ambient` | ESP32 | حرارة الجو |
| `/battery` | ESP32 | جهد البطارية ونسبة الشحن |
| `/controls` | الداشبورد | سرعة المروحة والطلمبة (0-100) — الـ ESP32 بيقراها |

## خطوات التشغيل

1. **Firebase**: اعمل مشروع على https://console.firebase.google.com ←
   ضيف Realtime Database ← انسخ قواعد `database.rules.json` في تبويب Rules ←
   اعمل Web App وخد الكونفيج بتاعها.
2. **حساب للـ ESP32**: من Authentication ← فعّل Email/Password ← ضيف يوزر
   (مثلاً `esp32@yourproject.com`).
3. **الداشبورد**: حط كونفيج الفايربيز في `firebaseConfig` أول `<script>`
   في `index.html`.
4. **الفيرموير**: نزّل المكتبات المكتوبة أول ملف `.ino`، املى الواي فاي
   وبيانات فايربيز في أول قسم، وارفع الكود على الـ ESP32.
5. افتح الداشبورد — علامة "بيانات تجريبية" البرتقالي هتبقى "مباشر"
   باللون التيل أول ما توصل أول قراءة.

## التوصيلات (الافتراضي، وكلها قابلة للتغيير من الكود)

| القطعة | طرف الـ ESP32 |
|---|---|
| 3 حساسات حرارة DS18B20 (على خط واحد مع مقاومة 4.7kΩ) | GPIO 4 |
| حساس حرارة الجو DHT22 | GPIO 15 |
| 3 حساسات قدرة INA219 (عناوين 0x40 / 0x41 / 0x44) | GPIO 21 (SDA)، 22 (SCL) |
| مقسم جهد البطارية (100k / 27k) | GPIO 34 |
| بوابة موسفت المروحة (PWM) | GPIO 25 |
| بوابة موسفت الطلمبة (PWM) | GPIO 26 |

عناوين الـ INA219 بتتحدد من نقاط اللحام A0/A1 على البوردة:
0x40 = من غير لحام، 0x41 = A0، 0x44 = A1.

## الوضع التجريبي

من غير فايربيز، الداشبورد بتولّد بيانات محاكاة واقعية (اللوح بدون تبريد
أسخن، والسلايدرز بتأثر فعلاً في الحرارة)، عشان تقدر تتمرن على العرض
كامل قبل ما الهاردوير يخلص.
